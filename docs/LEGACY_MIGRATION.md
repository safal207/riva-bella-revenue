# Riva Bella — восстановление старого сайта и перенос функций

## Канонический источник — старый концепт

Сайт: https://riva-bella-gazipasa-concept.safalex.chatgpt.site/

На 7–9 ноября 2026 года в истории проекта указаны 176 позиций, русская/турецкая/английская локализация, готовые иллюстрации, поиск, категории, избранное и список выбранных блюд. Первая серия включала 108 сгенерированных фотографий; число уникальных изображений последней версии без архива не подтверждено.

**Критичный блокер:** этот сайт требует авторизацию ChatGPT; оригинальный ZIP / исходники, исходный JSON-каталог и папка изображений не обнаружены в доступных файлах и в GitHub. Поэтому ветка НЕ восстанавливает старое меню и не должна автоматически заменять опубликованный сайт.

## Правильный порядок работ

1. Получить исходный ZIP (или доступный экспорт проекта с файлами и изображениями) из старого чата.
2. Распаковать в безопасную рабочую ветку, проверить список файлов, 176 SKU, реальные пути к изображениям, 3 языка и структуру цен; сохранить архив и снимок оригинала.
3. Импортировать старые данные **без замены на восемь демо-блюд**. Сохранить связь ID → категорию → языки → фото → цену, не подставлять недостающие значения.
4. Встроить три режима на **одном** каталоге и корзине:
   - Лента фото как в Robys: крупное фото целиком, лайк (локальный), поделиться, цена, добавить.
   - Плитка фото: быстрый визуальный обзор.
   - Список: компактный поиск по категориям и ценам.
   Сохранять фильтр, поиск, язык, избранное, выбранные блюда и их количество при смене режима.
5. Добавить ClickFunnels: первый выбор по намерению и понятная цепочка просмотр → детали → добавление → итог.
6. Добавить SamCart: только совместимые дополнения и понятные пары; не использовать ложные скидки или придуманную себестоимость.
7. Добавить Duolingo-подобную деликатную обратную связь: лёгкая анимация добавления, видимый прогресс выбора, сохранённые блюда, но без фальшивых счётчиков и манипуляций.
8. Провести каталоговый, визуальный, мобильный, языковой, клавиатурный и корзинный регресс; отдельно проверить 320/375/390/768/1440px.
9. Только после сравнения 176 позиций и подтверждения фотографий делать замену GitHub Pages. Никаких автоматических заказов и платежей без согласования владельца.

## Что готовит эта ветка

- Универсальный модуль src/view-modes.js, независимый от демо-данных.
- Переключение Feed / Grid / List, приватное избранное и шаринг deep links с единой корзиной.
- UI-адаптацию и локализацию TR/RU/EN.
- Автотесты правил отображения, настроек, фильтров, ссылок.
- Публичный GitHub Pages НЕ обновляется, пока PR не объединён с main.

## Принципы Robys, адаптируемые к Riva Bella

Источник: https://github.com/safal207/robys-coffee-house-demo/blob/main/docs/menu-photo-feed.md

Не клонировать бренд Robys и его фотографии. Использовать только поведение: три вида одной модели данных, ненавязчивое управление, фото без обрезки, локальные лайки (не публичная статистика), сохранение URL товара, отсутствие вымышленных счётчиков и мнимой активности.
