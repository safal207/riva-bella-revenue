# Riva Bella — проверяемый перенос меню

## Подтверждённый источник

12 ноября 2026 года на публичном QR-меню https://qrmn.net/rivabella были доступны 30 названий категорий. Их турецкие написания сохранены в data/source-categories.json, вместе с источником и датой. **Полные названия блюд, цены, ингредиенты, фотографии и наличие не подтверждены.** Встроенные восемь демо-товаров не являются меню ресторана.

## Процесс

1. Получить утверждённый владельцем список блюд и цен; сохранить ссылки на источник каждого товара.
2. Внести данные в data/catalog-draft.json, изначально в статусе draft.
3. Для каждого товара выбрать точную категорию из data/source-categories.json.
4. Подтвердить описания и названия на TR/EN/RU. Не придумывать состав или аллергены по фотографиям.
5. Проверить цену, наличие, права на фото (imageRights: owner-approved) и HTTPS-адрес изображения.
6. Сохранить владельческое подтверждение (ownerApprovedBy, ownerApprovedAt в ISO-8601) и перевести согласованную запись в статус approved.
7. Если аллергены неизвестны, установить allergenStatus: not-provided и показать потребителю предупреждение; иначе использовать verified и проверенный массив аллергенов.
8. Выполнить тесты и отдельно сформировать безопасный публичный экспорт. Импорт не подменяет демонстрационный каталог автоматически.

## Команды из корня репозитория

Аудит: node scripts/audit-catalog.mjs data/catalog-draft.json

Экспорт только согласованных записей: node scripts/audit-catalog.mjs data/catalog-draft.json --export out/public-menu.json

Пустой каталог или ошибки проверки блокируют экспорт. Экспортирует только разрешённые публичные поля; внутренние затраты, продажи, заметки и имя согласовавшего не включаются.

ВАЖНО: никогда не хранить настоящие закупочные цены, данные POS, продажи или другие коммерческие тайны в публичном GitHub. Действующая панель Revenue Lab демонстрационная и не имеет аутентификации. Сборка GitHub Pages копирует только index.html, styles.css и src/, но не data/.

Для настоящих заказов требуются согласование владельца, серверная проверка цен, защита от повторной отправки, интеграция POS и соблюдение KVKK. Текущая демо-корзина не отправляет заказ и не списывает деньги.
